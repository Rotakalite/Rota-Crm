<product_requirements>
The Rota-CRM system is a client consumption data management platform with dashboards and Clerk-based authentication. The development work in this trajectory addressed the following explicit user requirements:
1.  **Email System Refinement**: Improve email notification content for professionalism, ensure accurate data display (document names, folder paths, upload dates for document emails; training name, instructor, training date for training emails), and resolve undefined values. Automatic bulk email sending was to be avoided.
2.  **Supplier Management Module**: Implement functionality for selecting a client, adding new suppliers with details (company name, address, category, local/non-local, description, certifications, monthly purchase amount with units like KG, Litre, Adet, Gün), and listing existing suppliers filtered by the selected client. Display a pie chart showing local vs. non-local supplier ratios.
3.  **Personnel Management Module**: Create a new module to manage personnel information, including name, surname, position, residence-hometown, various certifications, local/non-local status, and gender. Display pie charts for local vs. non-local personnel and male vs. female ratios.
4.  **Role-Based Access Control (RBAC)**: Ensure that each client user can only view their own associated suppliers and personnel. Editing, adding, or deleting data should be restricted to admin users only. Client users' client selection should be automatic and non-editable.
5.  **Authentication Persistence**: Fix issues where users were unexpectedly logged out upon page refresh or encountered authentication errors during data submission.
6.  **Sustainability Targets Module**: Develop a brand new, separate module to enable clients to define, track, and report on measurable sustainability goals (e.g., environmental, social, economic KPIs).
</product_requirements>
